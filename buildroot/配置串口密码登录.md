# 将串口配置为密码登录
1. 设置登录密码：`pass root`
2. 设置串口登录启动带密码 shell
~~~shell
vim /etc/inittab
- ::respwawn:-/bin/sh # 使用这行不用登录
+ ttyFIQ0::respawn:/sbin/getty -L ttyFIQ0 0 vt100
~~~
