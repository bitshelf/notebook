# 使用帮助
| command                                        | Description  |
| ---------------------------------------------- | ------------ |
| `hdc_std list targets`                         | 查询设备列表 |
| `hdc_std file send D:\filename /data/filename` | 发送文件     |
| `hdc_std install file.hap`                     | 安装应用     |
| `hdc_std uninstall package`                    | 卸载应用     |
| `hdc_std hilog`                                | 抓取 log      |
