# OHOS 源码 SDK 编译
```shell
# 软件包安装
sudo apt install -y libxinerama-dev libxcursor-dev libxrandr-dev libxi-dev doxygen

# Windows SDK 编译
./build.sh --product-name ohos-sdk
```
- Windows SDK 生成路径：`out/sdk/ohos-sdk/windows`
