# 源码下载
```shell
repo init -u git@gitee.com:openharmony/manifest.git -b master --no-repo-verify
git clone https://gitee.com/bitshelf/local_manifests.git .repo/local_manifests -b OpenHarmony-4.0-Beta2
repo sync -c
repo forall -c 'git lfs pull'
bash build/prebuilts_download.sh
# 安装 hb
pip install build/hb
# 卸载 hb
pip uninstall ohos-build
```
1. repo 仓库下载
~~~shell
repo init -u git@gitee.com:openharmony/manifest.git -b refs/tags/OpenHarmony-v3.1.1-Release --no-repo-verify --mirror
~~~
* `-u`: 指定一个 URL，连接到一个 manifest 仓库
* `-m`：在 manifest 仓库中选择一个 xml 文件
* `-b`：选择一个 manifest 仓库中的一个指定分支
* `--repo-url`：设定 repo 的版本地址
* `--repo-branch`：设定需要检出的分支
* `--no-repo-verify`：设定不要对 repo 的里程牌签名进行严格的验证
* `--mirror`：只在 repo 第一次初始化的时候使用，建立本地镜像
* `-g ohos:standard`：下载标准系统指定芯片的代码（master 分支使用）

2. 同步下载代码
~~~shell
repo sync -c
~~~
- `-c`：当前分支
- `-j`：线程数
3. 下载大的二进制文件
~~~shell
repo forall -c 'git lfs pull'
~~~
4. 下载编译工具
~~~shell
bash build/prebuilts_download.sh
~~~
