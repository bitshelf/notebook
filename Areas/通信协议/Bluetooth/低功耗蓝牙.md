## 确定蓝牙bluez协议正常安装，并高于5.0
```shell
dpkg -l | grep bluez
```
## 查看蓝牙控制器是否正常启动
```shell
hciconfig

# 如果蓝牙状态不是 “UP RUNNING PSCAN” 则需要手动启动蓝牙
hciconfig  hci0 up
```

## 确定蓝牙功能是否被rfkill block
```shell
rfkill list

# 如果蓝牙被rfkill block，则需要通过rfkill命令unblock，否则蓝牙功能仍是被系统关闭的
rfkill unblock hci0
```

## 测试并验证低功耗蓝牙是否正常
```shell
# 用 hcitool lescan 命令扫描低功耗蓝牙设备
hcitool lescan
```
- 如果能够探测到低功耗蓝牙设备，代表蓝牙的基本功能正常

## 确定蓝牙正常可以ping通
```shell
l2ping 54:09:10:38:28:97
```

## 使用bluetoothctl工具
```shell
# 开启扫描
scan on

# 扫到自己的蓝牙设备之后，可以关闭蓝牙扫描
scan off

# 查看已经扫到的设备
devices

# 开启代理
agent on
default-agent

# 信任和配对
trust 54:09:10:38:28:97
pair 54:09:10:38:28:97

# 查看已经配对过的设备
paired-devices

# 连接蓝牙
connect 54:09:10:38:28:97

# 查看属性协议
menu gatt
	list-attributes
 
# 选择自定义的属性
select-attribute /org/bluez/hci0/dev_60_B7_4C_51_AC_D7/service0023/char0024
	attribute-info
# 读和写
	write 1
	read
```
###  gatttool 是用来访问 BLE 设备的命令
```shell
gatttool -b 20:91:48:6B:65:08 -I

# connect 表示连接远程设备，连接成功后，提示符签名的状态会显示 "CON"
connect

# primary 命令会列出远程设备上所有的 Service ，每个服务所在的 handle 范围
primary 

# 用 primary fee7 查看 UUID 为 0xfee7 的 Service 
primary fee7

# 执行 characteristics 0x0010 0x0017 可以发现它有三个 characteristic
characteristics 0x0010 0x0017
```
