#### 列出所有设备 
```shell
v4l2-ctl --list-devices
```

#### 查看摄像头支持预览格式
```shell
v4l2-ctl --list-formats-ext -d /dev/video0
```

#### 获取设备所有信息
```shell
v4l2-ctl --all -d /dev/video0
```

#### USB 摄像头查看支持的格式与分辨率
```shell
ffmpeg -f v4l2 -list_formats all -i /dev/video11
```

#### USB 摄像头抓图
```shell
gst-launch-1.0 -v v4l2src device=/dev/video11 ! image/jpeg,width=1280,height=720,framerate=30/1 ! tee name=t ! queue leaky=1 ! jpegparse ! jpegdec ! xvimagesink sync=false t. ! queue ! filesink location=testvideo.avi sync=false
```

#### Gstreamer 拍 jpg 图片
```shell
gst-launch-1.0 v4l2src device=/dev/video11 num-buffers=3 ! jpegenc ! filesink location=./pic021.jpg
```
