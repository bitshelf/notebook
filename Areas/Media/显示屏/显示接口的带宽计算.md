# 显示屏接口的带宽计算
```c
 disp_timings0: display-timings {
        native-mode = <&dsi0_timing0>;
        dsi0_timing0: timing0 {
                clock-frequency = <132000000>;
                hactive = <1080>;
                vactive = <1920>;
                hback-porch = <30>;
                hfront-porch = <15>;
                vback-porch = <15>;
                vfront-porch = <15>;
                hsync-len = <2>;
                vsync-len = <2>;
                hsync-active = <0>;
                vsync-active = <0>;
                de-active = <0>;
                pixelclk-active = <1>;
        };
};
```

按 60 帧刷新需要的 dclk 是：131994240 hz，dts 实际按取整 132000000 hz 配置
- $htotal=hfp+hsync+hbp+hactive=15+2+30+1080=1, 127$
- $vtotal=vfp+vsync+vbp+vactive=15+2+15+1920=1,952$
- $dclk=htotal\times vtotal\times fps=1127 \times 1952\times 60fps=131,994,240$

#### MIPI 接口上传输的频率是
$$\frac{132M \times 3 (RGB) \times 8 (bpc) }{4 (lane) \times0.9}=880Mbps $$
- $\times 3 (RGB)$ ：是每一个 pixel 有 RGB 3 个分量
- $\times 8 (bpc)$ ：是每一个分量的位深是 8bit
- $÷4 (lane)$ ：是这么多数据量在 4 lane 上传输，$÷4 (lane)$ 是计算每 lane 的数据量
- $÷0.9$ ：是考虑 mipi 时序的传输效率
