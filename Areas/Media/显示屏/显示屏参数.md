# 时序释义
* **LCD** 管脚：VD0~VD23：数据管脚   传送RGB
* **HSYNC**:当该管脚收到信号是，电子枪由最右端跳回最左端
* **VSYNC**:该管脚收到信号时，电子枪由右下角跳回左上角
* **VCLK**:：每个VCLK信号使电子枪跳到下一个像素点
* **VNEN**:视频数据使能电子枪接收VD0~VD23上的数据
* **HSPW**:HSYNC信号的脉冲宽度
 * **HBPD**:从水平同步信号到下一行有效信号的宽度，即电子枪从最右端回到最左端的时间
* **HOZVA**L:一行像素个数
* **HFPD**:打完一行像素到下一个水平同步信号，
* **VSPW**垂直同步脉冲宽度
* ***VBPD**:一针结束后，垂直同步信号以后的无效行数
 * **LINEVAL**:一共有多少行
* **VFPD**:一针结束后，垂直同步信号以前的无效行数
* **极性**：信号的极性根据外接LCD相应极性可配置

# DSI Clock 
* **HFP**: Horizon front porch 
* **HBP**: Horizon back porch 
* **VFP**: Vertical front porch 
* **VBP**: Vertical back porch 
* **HDP**: Horizon display period 
* **VDP**: Vertical display period 
* **HTP** = HSYNC + HDP + HFP + HBP 
* **VTR** = VSYNC + VDP + VFP + VBP
* $H_{total} = HorizontalActive + HorizontalFrontPorch + HorizontalBackPorch + HorizontalSyncPulse + HorizontalSyncSkew$

* $V_{total} = VerticalActive + VerticalFrontPorch + VerticalBackPorch + VerticalSyncPulse + VerticalSyncSkew$

* $Total pixel = H_{total} * V_{total} * 60HZ$(Hz通常都是这个，当然可以变)
* $Bitclk = \frac{Total\ pixel \times bpp(byte) \times 8}{lane\ number}$(lane number 有几路 mipi data lane)
* $Byteclk = \frac{bitclk}{8}$

* $Dsipclk(Dsi\ pixel\ clock) = \frac{Byteclk \times lane\ number}{bpp(byte)} = Total\ pixel * 8$
* $Byteclk = \frac{pclk \times pixel\ depth }{ lane\ number}$
* 每条MIPI data lane的传输速率$di\_hs\_clk = \frac{(h\_active + hfp + hbp + h\_sync)\times(v\_active + vfp + vbp + v_sync)\times fps \times bpp}{lane\_number}$
	* bpp 为像素位宽
