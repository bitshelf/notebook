# WAN 与 LAN 对比
|                          WAN                          |                           LAN                            |
|:-----------------------------------------------------:|:--------------------------------------------------------:|
|                        网速慢                         |                          网速快                          |
| 使用第三层设备（网络层），包括路由器、多层交换机、ATM | 大多数时候使用第一层或者第二层设备，包括交换机或者集线器 |
|                                                       |                                                          |
