# Linux 4G 拨号
> [!info] 文件格式
> * Windows 的 dos 格式每行以`\r\n`结尾
> * Linux 的文件默认以`\n`结尾
> * pppd 和 chat 不能解析 dos 格式的文件

## ppp 拨号
1. 拷贝 quectel-chat-connect、 quectel-chat-disconnect、 quectel-ppp 到`/etc/ppp/peers`目录下
	1. 修改`quectel-ppp`里的串口设备名、username、password
	2. 修改`quectel-chat-connect`修改 APN（APN/username/password 从网络供应商获取）
	3. 使用命令拨号：`pppd call quectel-ppp&`
2. 使用`quectel-pppd.sh`拨号
~~~shell
./quectel-pppd.sh /dev/ttyUSB3 APN username password
~~~

* ip-up: pppd: 在获取 IP 和 DNS 之后，会自动调用这个脚本来设置系统的 DNS
