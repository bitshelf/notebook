## `ip` 命令
|`ip`|`ifconfig`|
|---|---|
|`ip addr ls`| `ifconfig`|
|`ip link set dev eth0 up`|`ifup eth0`|
|`ip addr add 10.0.0.1/24 dev eth1`|`ifconfig eth1 10.0.0.1 netmask 255.255.255.0`|
|`ip route add 10.0.0/24 via 192.168.0.1`|`route add -net 10.0.0.0 netmask 255.255.255.0 gw 192.168.0.1`|
### 网关配置命令
* `route add default gw <网关ip>`
* `route add -host <指定ip> gw <网关ip>`
* `route add -net <指定网段> netmask <子网掩码> gw <网关ip>`
### 查看网络情况
1. 跟踪网络情况：`traceroute -w 1 www.baidu.com`
	* `-w`: waste 目标主机超时，最多等待一分钟
2. `mtr`:直接输入查看网络信息
3. `nslookup www.baidu.com`: 将域名解析为ip地址
4. `telnet www.baidu.com`:检查与主机端口的网络情况
5. `tcpdump -i any -n port 80 and host 10.0.0.1 -w /tmp/file`
	* `-i`: 
	* `any`: 所有网卡的数据包
	* `-n`: 将域名解析为ip地址
	* `host`: 捕获指定主机 
	* `-w`:保存到指定文件
6. 查看物理网卡连接情况
	~~~shell
	mii-tool eth0
	~~~
### 查看网路情况
*  `route -n` 使命 `-n` 参数不解析主机名，更快查看结果

## 网卡命名规则
> 网卡命名规则受`biosdevname`和`net.ifnames`两个参数的影响

1. 编辑`/etc/default/grub`文件，增加`biosdevname=0 net.ifnames=0`
2. 更新`grub` 
~~~shell
grub2-mkconfig -o /boot/grub2/grub.cfg
~~~
3. 重启

| |`biosdevname`|`net.ifnames`|网卡名|
|---|:---:|:---:|---|
|默认|$0$|$1$|`ens33`|
|组合1|$1$|$0$|`em1`|
|组合2|$0$|$0$|`eth0`|
# 网络服务管理
## SysV
1. `service network start|stop|restart`
2. `chkconfig -list network` ：查看网络状况
3. `chkconfig --level 2345 network off` :禁用SysV
4. `service network status`: 查看网络状态
## systemd
1. `systemctl list-unit-files NetworkManager.service`：查看网络状态
2. `systemctl start|stop|restart NetworkManager`
3. `systemctl enable|disable NetworkManger`
### 配置文件
* `ifcfg-eth0` 网卡的配置文件
* `/etc/hosts` 主机的网络配置文件
* `/etc/sysconfig/network-scripts/`:网络配置文件所在目录
