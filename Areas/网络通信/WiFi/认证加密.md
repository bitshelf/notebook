# 4 种认证/加密
1. open
2. WEP
3. WPA(TKIP)
4. WAP2(AES)
## 工具使用
* 旧工具 `iwconfig`，`iw` 是它的替代，可用于 open、WEP 两种认证加密
* `wpa_supplicant` ：可以用于四种认证加密
## 示例
~~~shell
network={
	proto="apname"
	key_mamt=WPA-PSK
	pairwise=TKIP
	psk="passwork"
}
~~~
* `proto=WPA` ：protoc：list of accepted protocols, 可取 WPA，RSN
* `key_mgmt=WPA-PSK` : 认证方式。If not set, this defaults to: WPA-PSK WPA
# 连接
1. `wpa_supplicant -B -c/etc/wpa_wpa2.conf -iwlan0`
2. 查看连接状态：`wpa_cli -iwlan0 status`
