# repo
```shell
repo init -u git://xxx/xxx/manifest.git -b <BRANCH> -m <MANIFEST>
```
-  `-u`: 指定从哪儿仓库下载
-  `-m`: 从 manifest 库中指定一个 manifest 名称。如果没有指定，默认是 default.xml.
-  `-b`: 指定分支
- `-g`：指定项目组
