# Rust 编写的程序
> [!info] Rust 安装
> ```shell
> curl --proto '=https' --tlsv1.3 https://sh.rustup.rs -sSf | sh
> ```


## Rust 程序
```shell
cargo install broot --locked # tree
cargo install topgrade --locked
cargo install procs # ps
cargo install fd-find
cargo install ripgrep
cargo install du-dust # du
cargo install rm-improved # rm
cargo install xcp # cp
cargo install lsd # ls
cargo install bat --locked # cat
cargo install alacritty # terminal
```
