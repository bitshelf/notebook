1. 点运算符 ($.$) 表示调用对象的成员。点运算符只能用于类型类型的对象。
2. 当用点运算符访问一个成员函数时，通常是想调用函数。使用调用运算符$()$来调用一个函数。

> 调用运算符是一对圆括号，里面放置实参列表（列表可能为空）。
## 注释
注释可以用来阐述目的、用途、工作原理、注意事项等代码本身无法“自说明”的信息。
## return
不带表达式的 $return$ 语句将把控制权返回给调用者，但不返回有用的值。等同于在到达函数的右终结花括号时，函数“到达了尽头”。主函数也可以忽略函数返回的值。
## 自动变量

自动变量只在函数调用执行期间存在，因此，在函数的两次调用之间，自动变量不保留前次调用时的赋值，且在每次进入函数时都要显式为其赋值。如果自动变量没有赋值，则其中存放的是无效值。
## 外部变量
外部变量必须定义在所有函数之外，且只能定义一次，定义后编译程序将为它分配存储单元。在每个需要访问外部变量的函数中，必须声明相应的外部变量，此时说明其类型。声明时可以用***extern***语句显式声明，也可以通过上下文隐式声明。在某些情况下可以省略***extern***声明。在源文件中，如果外部变量的定义出现在使用它的函数之前，那么在那个函数中就没有必要使用***extern***声明。
> 为了提高易读性，可以成员变量前加 $m\_$，全局变量前加 $g\_$。
## 函数参数
不带参数的函数必须使用***void***显式声明。函数参数括号里留空，为了与老版本的程序兼容，则不对参数列表进行任何检查。
## “定义 $(define)$ ”与“声明 $(declaration)$ ”
定义：表示创建变量或分配内存存储单元。
声明：说明变量的性质，但并不分配存储单元。
## 预处理
在预处理阶段 ***(pre-process)***，是文本替换，不涉及语法。
**typedef** 是在编译阶段。

## `*` 间接运算符

* `sum += n;` `+=` 复合运算符，产生一条机器指令; 整个 `sum += n;` 称为复合表达式
* `while(sum += n++, n < r);while` 会根据表达式 `n < r ` 的值进行循环，`;` 表示空语句

#### 字符串化 `#`

```c

```


无`#`

```c

```


宏连接`##`

参数有`#`或者`##`运算符时，参数不展开

```c
#define A(a,b) a b
A(x,x);//输出 a b

#define A(a,b) ab
A(x,x);//输出 ab

#define A(a,b) a##b
A(x,x); //输出xx

#define A hello
#define B(x,y) x##y
#define C(z) #z
#define D(x) x

B(a,b);//结果为 ab
C(A);//结果为"A"
D(A); //结果为 hello

```
