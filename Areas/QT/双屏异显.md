# 双屏异显
* 测试平台： RK3568 buildroot
* RK平台默认配置为双屏同显，参看以下修改即可配置为双屏异显

* 配置方法一
~~~shell:/etc/init.d/S50launcher
# Uncomment to disable mirror mode
-# unset WESTON_DRM_MIRROR
unset WESTON_DRM_MIRROR
~~~

* 配置方法二
~~~shell:/etc/profile.d/weston.sh
-export WESTON_DRM_MIRROR=1
+# export WESTON_DRM_MIRROR=1
~~~

修改以上配置文件后，重启生效
执行以下命令确认WESTON_DRM_MIRROR配置是否生效
~~~shell
echo $WESTON_DRM_MIRROR
~~~
