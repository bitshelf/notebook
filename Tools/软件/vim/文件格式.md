> [!info] 文件格式
> * Windows 的 dos 格式每行以`\r\n`结尾
> * Linux 的文件默认以`\n`结尾

## 文件格式转化工具
* dos2unix
1. 设置文件格式
~~~vim
:set fileformats=unix,dos
~~~
2. 查询当前文件格式
~~~vim
:set fileformat?
~~~
3. 转换文件格式
~~~vim
:set fileformat=unix
~~~
4. 设置文件结束符
~~~vim
:set endofline
~~~
5. 去掉文件结束符
~~~vim
:set noendofline
~~~
6. 显示换行
~~~vim
:set list
~~~
7. 退出list mode
~~~vim
:set nolist
~~~
8. 删除换行符
~~~vim
:%s/\n//g
~~~
