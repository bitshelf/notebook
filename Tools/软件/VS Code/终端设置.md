# Vscode 终端设置
## 登录终端自动执行脚本
1. 打开服务器配置 json 文件
```json
{
    // terminal configuration

    "terminal.integrated.profiles.linux": {

        "terminal": {

          "path": "bash",

          "args": [

            "--init-file",

            "${workspaceFolder}/../.config/terminal.sh"

          ]

        }

      },

      "terminal.integrated.defaultProfile.linux": "terminal",
}
```
### 修改 vscode 配置文件
```json
"terminal.integrated.profiles.linux": {
  "BashWithStartup": {
    "path": "bash",
    "args": [
      "--init-file",
      "/home/rpdzkj/fourth/loh95/.terminal_startup.sh"
    ]
  }
},
"terminal.integrated.defaultProfile.linux": "BashWithStartup",
```
#### 启动配置脚本
```shell
eval "$(starship init bash)"
eval "$(zoxide init bash)"
[ -f ~/.fzf.bash ] && source ~/.fzf.bash
```

### 修改 `~/.bashrc`
```shell:~/.bashrc
if [ "x$TERM_PROGRAM" = "xvscode" ]; then
    eval "$(starship init bash)"
    eval "$(zoxide init bash)"
fi
```

### 修改 vscode 配置文件（不推荐）
`$` 换行设置，在`~/.vscode-server` 的 `shellIntegration-bash.sh` 添加以下脚本
```shell
if [[ `pwd` =~ loh ]]; then
        export PS1='${debian_chroot:+($debian_chroot)}\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\r\n\$ '
fi
```
