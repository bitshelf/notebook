# vim 快捷键
## easymotion
1. `<leader> <leader> s <char>`
2. `<leader><leader> ge ` : End of word backwards
3. `<leader><leader> / <char>... <CR>`  Search n-character
## vim-surround
1. `d s <existing>` Delete `existing` surround
2. `c s <existing> <desired>` Change `existing` surround to `desired`
# VSCodeVim tricks
1. `gd` - jump to definition
2. `gb` - adds another cursor on the next word it finds which is the same as the word under the cursor
3. `af` - visual mode command which selects increasingly large blocks of text
