# 数学符号
|                      符号                      |                      代码                      |
|:----------------------------------------------:|:----------------------------------------------:|
|                     $\sum$                     |                    `$\sum$`                    |
|                    $\not=$                     |                   `$\not=$`                    |
| $\overbrace{a+\underbrace{b+c}_{1.0}+d}^{2.0}$ | `\overbrace{a+\underbrace{b+c}_{1.0}+d}^{2.0}` |
|                   $\uparrow$                   |                  `$\uparrow$`                  |
|                  $\downarrow$                  |                 `$\downarrow$`                 |
|                   $\Uparrow$                   |                  `$\Uparrow$`                  |
|                 $\Rightarrow$                  |                `$\Rightarrow$`                 |
|                    $\alpha$                    |                   `$\alpha$`                   |
|                    $\beta$                     |                   `$\beta$`                    |
|                     $\pi$                      |                    `$\pi$`                     |
|               $\lbrace \rbrace$                |     `$\lbrace \rbrace$`      或者 `\{, \}`     |
|                      \mu                       |                     `\mu`                      |
|                   $\lambda$                    |                  `$\lambda$`                   |
| $\sqrt{a + b}$                                               |           `$\sqrt{a + b}$`                                     |
