# Obsidian 语法
1. 锚点链接：`[显示的链接字体](#标题)`
2. 图片：`![图片无法显示时的替代文字](图片地址)`
3. 下划线： `<u>下划线</u>`
4. 链接显示空格 `(< >)` ：[显示空格](<https://wiki.gentoo.org/wiki/Udev/zh-cn>)
