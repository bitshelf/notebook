## 限制编译线程
```shell
export BB_NUMBER_THREADS="16"
export PARALLEL_MAKE="-j16"
```

```
                      ┌────────────────────────────────────┐
                      │          BitBake 调度器             │
                      │                                    │
                      │       BB_NUMBER_THREADS = 16       │
                      │       (最多并行执行 16 个 Task)      │
                      └─────────────────┬──────────────────┘
                                        │
                  ┌─────────────────────┼─────────────────────┐
                  │                     │                     │
        ┌─────────┴──────┐    ┌─────────┴──────┐              │
        │                │    │                │              │
        ▼                ▼    ▼                ▼              ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│    glibc     │  │   busybox    │  │     zlib     │  │ 其他 Recipe  │
│  do_compile  │  │  do_compile  │  │  do_compile  │  │  do_compile  │
└──────┬───────┘  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘
       │                 │                 │                 │
       ▼                 ▼                 ▼                 ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│   make -j16  │  │   make -j16  │  │   make -j16  │  │   make -j16  │
└──────────────┘  └──────────────┘  └──────────────┘  └──────────────┘
```
- 仅示意支持 `PARALLEL_MAKE` 的编译任务。并非每个 Task 都会启动 16 个编译 Job
```shell
# 确认是否生效
bitbake -e | grep -E '^(BB_NUMBER_THREADS|PARALLEL_MAKE)='
```
### 在 local.conf 
```bitbake
# BitBake 同时执行的最大任务数量
BB_NUMBER_THREADS = "16"

# 单个 Recipe 编译时的 Make 并行度
PARALLEL_MAKE = "-j16"
```

## 限制拉取时的线程数
```
do_fetch[number_threads] = "8"
```
