## 限制 CPU 使用率
```shell
# 修改默认编辑器为 vim
sudo update-alternatives --config editor

# 查看用户 ID
id

# 根据 ID 限制用户 CPU 使用率
sudo systemctl edit --force --full "user-$(id -u).slice"
```

```conf
# /etc/systemd/system/user-1002.slice
[Slice]
CPUQuota=2400%
```

然后执行
```
sudo systemctl daemon-reload

# 处于 active 状态的 user-1001.slice 立即生效
sudo systemctl set-property user-1001.slice CPUQuota=2400%

systemctl show user-1001.slice \
    -p CPUQuotaPerSecUSec \
    -p CPUQuotaPeriodUSec
```

## 所有用户都使用同一配置
创建通配型 drop-in
- `sudo mkdir -p /etc/systemd/system/user-.slice.d`

```title:/etc/systemd/system/user-.slice.d/50-cpu-quota.conf
[Slice]
CPUQuota=2400%

# 软限制：达到时开始限制和回收内存
MemoryHigh=60G

# MemoryMax 是硬限制：超过后 slice 内触发 OOM 
MemoryMax=32G

# IO 统计与限制
IOAccounting=yes

# I/O 相对权重（默认 100)
IOWeight=80

# 绝对 IO 带宽限制，需要按块设备设置 # 把 /dev/nvme0n1 换成你的实际磁盘 IOReadBandwidthMax=/dev/nvme0n1 200M 
IOWriteBandwidthMax=/dev/nvme0n1 100M

# 限制 swap，0 表示不允许该 slice 使用 swap
MemorySwapMax=0
```
- `sudo systemctl daemon-reload`

验证
```shell
systemctl cat "user-$(id -u).slice"

systemctl show "user-$(id -u).slice" \
    -p CPUQuotaPerSecUSec
    
# 查看 user-.slice 当前状态
systemctl status user-.slice

# 验证具体限制参数是否已生效
systemctl show user-.slice -p MemoryMax -p MemoryHigh -p CPUQuota -p IOWeight
```
