方案一：QEMU 原生模拟流 ^TCWs1r8H

【架构原理】
宿主机仅提供内核，通过 QEMU-Static
进行用户态指令动态翻译(binfmt)。
Chroot 内部完全是纯粹的 ARM64 环境。
速度较慢，但兼容性 100%。 ^bVcHUQHh

【核心搭建步骤】
1. 安装基础工具：
   $ apt install schroot debootstrap \
     qemu-user-static binfmt-support

2. 初始化 ARM64 根系统(第一阶段)：
   $ debootstrap --arch=arm64 --foreign \
     jammy ./jammy-arm64 [源URL]

3. 挂载 QEMU 解释器：
   $ cp /usr/bin/qemu-aarch64-static \
     ./jammy-arm64/usr/bin/

4. 触发第二阶段初始化：
   $ chroot ./jammy-arm64 \
     /debootstrap/debootstrap --second-stage

5. 配置 schroot 并进入：
   $ schroot -c jammy-arm64 ^VxSfRWlc

方案二：Ubuntu Sysroot 混合流 ^J8QitIdK

【架构原理】
充分发挥 x86 多核性能。编译器运行在
x86 宿主机上，但将 Chroot 目录指定为
--sysroot。利用 QEMU 在 Chroot 内装库，
利用 x86 编译器高速产出 ARM 固件。 ^fX3q0rhb

【核心搭建步骤】
1. 宿主机安装交叉编译器：
   $ apt install crossbuild-essential-arm64

2. 完善 schroot 挂载配置：
   在 conf 中加入 profile=default
   使其自动映射宿主机 /home 目录

3. 利用 QEMU 快捷部署 ARM 依赖库：
   $ schroot -c jammy-arm64
   (进入后) # apt install libssl-dev
   $ exit (退出容器)

4. 宿主机全速交叉编译：
   $ aarch64-linux-gnu-gcc main.c \
     --sysroot=/path/to/chroot -lssl ^4TaGNBit

方案三：Debian Multiarch 原生流 ^czXU1MEL

【架构原理】
极致优雅。彻底抛弃 Chroot 容器隔离。
通过 dpkg 允许系统混合共存多架构库。
x86 库和 ARM64 库直接平铺在宿主机系统
目录中，互不干扰，工具链原生感知。 ^8GZyzbY9

【核心搭建步骤】
1. 宿主机注册外来架构：
   $ dpkg --add-architecture arm64

2. 拆分配置 sources.list 源：
   设置 [arch=amd64] 指向常规源
   设置 [arch=arm64] 指向 ports 源
   $ apt update

3. 原生混合安装编译器与 ARM64 库：
   $ apt install crossbuild-essential-arm64
   $ apt install libssl-dev:arm64

4. 零 Sysroot 路径直接编译：
   $ export PKG_CONFIG_PATH=\
     /usr/lib/aarch64-linux-gnu/pkgconfig
   $ aarch64-linux-gnu-gcc main.c -lssl ^mHnjhZTb

方案四：★ 官方首选 Docker 容器流 ^h2ScYFAy

【架构原理】
工业级标准。将“Multiarch 高速编译”
封装进独立的 Docker 沙盒镜像。不修改
宿主机任何配置，完美隔离不同项目的库
与工具链版本。代码目录动态挂载，
产物直接输出宿主机。 ^Vw5b2uEl

【核心搭建步骤】
1. 编写 Dockerfile 沙盒化多架构：
   FROM ubuntu:22.04
   RUN dpkg --add-architecture arm64
   # [换源后安装工具链与 ARM64 依赖]
   RUN apt-get update && apt-get install -y \
       crossbuild-essential-arm64 \
       libssl-dev:arm64 libqt5core5a:arm64
   ENV PKG_CONFIG_PATH=/usr/lib/aarch.../

2. 构建独立项目编译镜像：
   $ docker build -t arm64-compiler:v1 .

3. 挂载宿主机源码，一行命令高速产出：
   $ docker run --rm -v $(pwd):/workspace \
     arm64-compiler:v1 \
     aarch64-linux-gnu-g++ main.cpp -lssl ^PeiZtj1e
