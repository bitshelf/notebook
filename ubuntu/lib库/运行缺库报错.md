# Ubuntu 运行缺库
## LIBJPEG_8.0
> [!error] LIBJPEG_8.0
> ```shell
> mpv: /usr/lib/aarch64-linux-gnu/libjpeg.so.8: version `LIBJPEG_8.0' not found (required by mpv)
>```

- 根据 `aptitude reinstall libjpeg` 提示重新安装软件包
- 解决办法：
```shell
sudo aptitude reinstall libjpeg-turbo8-dev
# 或者
sudo apt install --reinstall libjpeg-turbo8
```
