# 搜索多 PDF 文件
#### pdfgrep
```shell
sudo apt instll pdfgrep
```

#### rust rga
```shell
apt install build-essential pandoc poppler-utils ffmpeg ripgrep 
```

```shell
cargo install --locked ripgrep_all
```

- 参考：[GitHub - phiresky/ripgrep-all: rga: ripgrep, but also search in PDFs, E-Books, Office documents, zip, tar.gz, etc.](https://github.com/phiresky/ripgrep-all)
