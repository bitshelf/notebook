# Longan 系统介绍
longan 是 lichee 和 kunos 合并后的名称，同时也兼容新的 Tina 5.0 方案。它集成了 BSP，构建系统，独立 IP 和测试，既可作为 BSP 开发和 IP 验证平台，也可以作为量产的嵌入式 linux 系统
- BSP 开发，包括 bootloader，uboot 和 kernel
- Linux SDK 开发，包括量产的嵌入式 linux 系统
- IP 的验证和发布平台
- 测试，包括板级测试和系统测试，如 SATA 和 drangonboard
