# 编解码
![编解码系统框架.excalidraw](Resource/编解码/编解码系统框架.excalidraw.md)

|   模块    |                  功能                   |
|:---------:|:---------------------------------------:|
|   ADEC    |                音频解码                 |
|   AI/AO   |              音频输入/输出              |
| VDEC/VENC |             视频编解码输出              |
|    RGN    |            视频 OSD 信息叠加            |
|    TDE    | 硬件 RGA 快速处理，旋转、拷贝、格式转化 |
| VO          |                       视频显示输出管理，支持多图层、多 VOP 显示                  |

# MPP
* **MPP**：媒体处理软件平台（Media Process Platform）
* 向上提供 MPI 接口，提供编解码接口，适配操作系统层。向下连接、VPU 硬件设备驱动
