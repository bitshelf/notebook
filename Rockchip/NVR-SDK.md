>NVR SDK 在适配NVR以及显控，会议系统等产品开发，基于Linux的一套精简SDK
## SDK 目录
~~~shell
|- docs 存放开发指导文件、平台支持列表、工具使用文档、Linux开发指南
|- kernel 存放kernel代码
|- rkbin 存放Rockchip 相关Binary和工具
|- tools 存放SDK配套的PC端工具
|- u-boot 存放uboot代码
|- IMAGE 存放每次完整编译产生的镜像、补丁、编译信息等       
|- rockdev 存放编译输出的分立固件
|- build 存放编译脚本、根文件系统以及工具链等
|- .repo 存放版本repo信息
~~~
