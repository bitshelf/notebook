# RK809
#### 内核 RK809 驱动源码对应位置
- `drivers/mfd/rk808.c`
- `drivers/input/misc/rk805-pwrkey.c`
- `drivers/pinctrl/pinctrl-rk805.c`
- `drivers/regulator/rk808-regulator.c`
- `drivers/clk/clk-rk808.c`

#### config 配置文件
1. `CONFIG_MFD_RK808`
2. `CONFIG_RTC_DRV_RK808`
3. `CONFIG_PINCTRL_RK805=y`
4. `CONFIG_INPUT_RK805_PWRKEY=y`
5. `CONFIG_COMMON_CLK_RK808=y`
6. `CONFIG_REGULATOR_RK808=y`
