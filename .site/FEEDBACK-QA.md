## 后续反馈

- 手机目录选中无法跳转：修复遮罩层级；实际触摸展开 Allwinner/编译 并进入“编译报错”，断言地址与正文变化、抽屉关闭。
- 手机目录：主题图标与菜单按钮同排，打开目录后显示。目录列表独立滚动。
- 页脚：隐藏 Quartz 署名，取消固定占位。
- 手机首页和目录：阅读模式按钮仅在桌面显示，避免挡住 Home。测试从 wpa_cli 返回首页，再打开目录并展开 Allwinner。
- 右侧栏：收起关系图谱后目录上移，收起目录后标题列表隐藏。
- GPIO 笔记：构建时把原有的 Markdown 章节嵌入交给 Obsidian 渲染器；检查被引用的设备树章节和内嵌手绘图均可见。
- 目录和文件区分：列表输出 folder/note 语义并显示不同图标。
- 左侧查找文件：只匹配文件名，不匹配正文；右上角综合搜索仍匹配文件名、标题、路径、正文与标签。
- 列宽手柄：去掉误导箭头，把命中区放在本列表头内部，防止被下一列覆盖；测试真实拖动 40px 后列宽变化。
- 手机画布侧栏关闭按钮与搜索重叠：展开原生侧栏时隐藏快捷栏，关闭后恢复；两类画布均执行侧栏主题与返回导航检查。
- 白板、手绘图、Mermaid：检查真实页面、容器宽度、交互与相应缩放按钮；Pele SVG 实际挂载。

## 重跑方法

```powershell
cd .site
npm ci
npm run build
npx playwright install chromium firefox
npm run test:site
npm run test:generated
npm run test:browser
```

Windows 默认使用已安装的 Edge；Linux CI 使用 Playwright Chromium 与 Firefox。
线上复验可设置 `QA_URL=https://bitshelf.github.io/notebook/` 后运行浏览器测试。
