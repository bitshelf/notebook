## Android studio 导入 jar 包
1. 在 `app/libs` 放入 `xxx.jar`
2. 2. 右键 jar 包，选择“Add As Library”或者 （**菜单 File** -> **Project Structor** -> **Modules** -> **Dependences** 点击 $+$ ，选择 **File dependency**，选择导入 jar 包）

## Android studio 导入 so 库
- 在 `src/main` 目录下新建 `jniLibs` 目录，放入 so 库
