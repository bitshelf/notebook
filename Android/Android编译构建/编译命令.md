# Android 编译命令
1. 获取某个编译变量的值，是绝对路径`get_abs_build_var`
2. 打印各种编译变量的值：`printconfig`
3. 打印lunch可选择的各种product：`print_lunch_menu`
4. 得到prebuilt的路径：`getprebuilt`
5. 获取TARGET_ARCH的值：`gettargetarch`
6. 获取Android源码根目录：`gettop`
7. 将编译要用到的一些路径添加到环境变量 PATH 里：`setpaths`
