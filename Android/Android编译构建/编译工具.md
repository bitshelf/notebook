# Android 编译工具
### Jack
jack 的主要任务是取代以前版本中的 javac、ProGuard、jarjar、dx 等诸多工具，换一种方式将 Java 源文件编译成 Android 的 Dex 字节码

#### Ubuntu 更改默认 Java 版本
~~~shell
sudo update-alternatives --config java
sudo update-alternatives --config javac
~~~
- 参考：[https://source.android.com/source/initializing.html](https://source.android.com/source/initializing.html)
