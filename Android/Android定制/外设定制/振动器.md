## Android 添加震动
```c
vibrator {
        compatible = "rk-vibrator-gpio";
        vibrator-gpio = <&gpio2 RK_PA3 GPIO_ACTIVE_HIGH>;
        status = "okay";
    };
```

```Makefile
# BoardConfig.mk
BOARD_ROCKCHIP_VIBRATOR := true
```

```Makefile
# .config 
CONFIG_ANDROID_TIMED_OUTPUT=y
CONFIG_ANDROID_TIMED_GPIO=y
```
