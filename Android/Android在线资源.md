AOSP(Android Open Source Project)项目官网：[https://source.android.com/](https://source.android.com/)  
如果想了解如何将源码下载到本地进行查看，请直接参考[https://source.android.com/setup/downloading](https://source.android.com/setup/downloading)，里面有介绍。

AOSP源码占用空间较大，有时不方便通过下载到本地的方式进行查看，可以考虑使用下列网址在线查看：

-   Android Code Search: [https://cs.android.com/](https://cs.android.com/)
-   AOSPXRef: [http://aospxref.com/](http://aospxref.com/)
-   androidxref: [http://androidxref.com/](http://androidxref.com/)
-   Android Cross Reference: [http://aosp.opersys.com/](http://aosp.opersys.com/)
-   Android OS: [https://www.androidos.net.cn/sourcecode](https://www.androidos.net.cn/sourcecode)
-   Git repositories on android: [https://android.googlesource.com/](https://android.googlesource.com/)

其它曾经关注的AOSP相关网址：

-   Building Android: [https://source.android.com/setup/build/building](https://source.android.com/setup/build/building)
