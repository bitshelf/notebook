# 模块异常排查
1. 检查 RIL daemon 进程是否运行
```shell
getprop init.svc.ril-daemon
```

2. 查看库是否使用正确
```shell
cat /vendor/etc/init/*rild.rc |grep ril-daemon
```

3. 查看库版本
```shell
getprop gsm.version.ril-impl
```
5. 关闭 SELinux，查看模块是否正常工作
```shell
getenforce # 获取SELinux状态
setenforce 0 # 关闭SELinux
```
