## 基础概念
### SUID（Set User ID）

SUID 是一种特殊的文件权限位，当一个可执行文件设置了 SUID 权限时，任何用户运行该文件时，都会以文件所有者的权限运行。这在某些需要高权限操作的场景下非常有用，但也可能带来安全风险。

### SGID（Set Group ID）

SGID 是另一种特殊的文件权限位，当一个可执行文件或目录设置了 SGID 权限时，运行该文件的用户会临时获得文件所属组的权限。对于目录，SGID 还可以确保在该目录下创建的文件自动继承目录的组所有权。

### Sticky Bit（粘滞位）

Sticky Bit 是一种特殊的目录权限位，当设置在目录上时，可以防止用户删除或重命名其他用户的文件，即使他们对该目录有写权限。这通常用于公共目录，如 `/tmp`，以防止用户删除其他用户的文件。

### 文件权限

文件权限是 Linux 系统中用于控制用户对文件和目录访问权限的机制。权限分为三类：所有者（user）、组（group）和其他用户（others）。每类权限可以设置为读（r）、写（w）和执行（x）。

## 查看文件权限
```shell
ls -l /path/to/file
-rwsr-xr-x 1 root root 12345 Jun 1 12:34 /path/to/file
```
- `rwsr-xr-x`：文件权限。
- `rws`：所有者权限，其中 `s` 表示 SUID。
- `r-x`：组权限。
- `r-x`：其他用户权限。
