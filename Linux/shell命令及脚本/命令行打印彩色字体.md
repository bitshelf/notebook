# 终端输出彩色字体
*  `\e[1;31m` 是一个转义字符串，可以将颜色设为红色，`\e[0m` 将颜色重新置回
*  `\e[1`
	* $0$ 终端默认设置（黑底白字）  
	* $1$ 高亮显示  
	* $4$ 使用下划线  
	* $5$ 闪烁  
	* $7$ 反白显示  
	* $8$不可见
> [!info] 彩色背景
> 重置=0，黑色=40，红色=41，绿色=42，黄色=43，蓝色=44，洋红=45，青色=46，白色=47
> 

要设置彩色背景的话，可输入如下命令：
```shell
echo -e "\e[1;42m Green Background \e[0m"
```
*  `\e` :escape
