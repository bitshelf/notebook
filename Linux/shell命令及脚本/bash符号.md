# 输入输出重定向
~~~shell
grep -i $1<<EOF
~~~
* `<<` 语法表示我们想创建一个临时输入源，`EOF` 是一个任意的字符串（你想用什么都行），用作临时输入的终止符
## 避免意外覆盖文件
~~~shell
set -o noclobber #开启选项
set +o noclobber #关闭选项
~~~
* `noclobber` 选项仅针对 shell 重定向输出时的文件覆盖行为。它并不能阻止其他程序覆盖文件
