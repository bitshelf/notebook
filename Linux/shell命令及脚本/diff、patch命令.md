# diff
##  `diff` 有三种模式
* `c` :change, 内容更改
* `a` ：add，内容增加
* `d` ：deletion，内容删除
## 参数选项
*  `-N` / `--new-file` ：将不存在的文件当作空文件
* `-u` ：默认输出每个修改前后的 3 行，也可以用 `-u5` 等指定输出更多上下文
* `-r` ：递归比较各子目录下的文件
## 正常 diff 格式
*  `<` 小于号表示从第一个文件去除该行
*  `>` : 表示第二个文件增加该行
## 上下文格式
~~~shell
diff -c f1 f2
~~~
使用方法是加入参数 `c`（context）
* `!` : 该行有改动
* `-` : 该行被删减
* `+` ：该行新增
## 合并格式
~~~shell
diff -u f1 f2
~~~
使用方法加入 `-u`（unified）
* `---` : 表示变动前的文件
* `+++` : 表示变动后的文件
* 变动的位置用两个 `@` 作为起首和结束
~~~shell
@@ -1,7 +1,7 @@
~~~
* `-` : 减号表示第一个文件
* `+` : 表示变动后，成为第二个文件
