# find
`find [-H] [-L] [-P] [path...] [expression]`
* `-H`表示只跟随命令行中指定的符号连接
* `-L`表示跟随所有的符号连接
* `-P`是默认的选项，表示不跟随符号连接
* `[expression]`是一个表达式。最基本的表达式分为三类：
	* 设置项(option):如`-depth,-maxdepth`
	* 测试项(test):`-name,-num,-user`
	* 动作项(action):`-print`

## 文件名使用正则表达式
```shell
#查找文件名以一个大写字母开头或者以小写a或b开头的文件
	find . -name "[A-Za-b]*" -print 
	```
* 匹配时不考虑大小写可以使用`-iname`
* `-regex`同样属于测试项。使用`-regex`时有一点要注意：`-regex`不是匹配文件名，而是匹配完整的文件名（包括路径）
>用"`abr9`"来匹配，将查找不到任何结果，正确的方法是使用"`.*ab.*9`"或者"`.*/ab.*9`"来匹配 

查找以数字开头的c代码的问题，可以这么写： 
```shell
$ find . -regex ".*/[0-9]*/.c" -print
```

## wholename与path
一般格式是：`find [path ...] -path pattern ...`
`-wholename`和`-path`都属于测试项(test)，而且功能也一样`
```shell 
find . -path '*phone/pu*'
```
它的意思是：在`[path ...]`部分指明的路径上，使用pattern匹配所有文件的完整文件名；而不是说在类似的pattern目录下查找文件

## uniq 
* `uniq` 只会检测相邻的重复行
* 使用 `-d` 参数,只是显示重复的行
* 使用 `-u` 参数，那样就只会显示不重复的行
* 使用 `-c` 参数计算每一行的出现次数
