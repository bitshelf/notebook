## 字符设备驱动注册
### 新接口
```c
register_chrdev_region // 手动分配是设备号
	__register_chrdev_region

alloc_chrdev_region // 自动分配设备号
	__register_chrdev_region
```

### 老接口
```c
register_chrdev
	__register_chrdev
		__register_chrdev_region
		cdev_alloc
		cdev_add
```

### 相关函数
```c
cdev_alloc()
cdev_init()
cdev_add()
cdev_del()
```
