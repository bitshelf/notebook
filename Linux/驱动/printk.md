# printk
## 内核打印函数名、文件名、行号
```c
printk（"[%s] %s %d\n",__FILE__,__FUNCTION__,__LINE__);
```

## 应用程序打印函数名、文件名、行号
```c
printf("%s %s %s: %d\n",__DATE__,__TIME__,__FILE__,__func__,__LINE__);
```


| 宏 | 功能 |
| --- | --- |
| \_\_FILE\_\_ | 当前程序文件名的字符串 |
| \_\_FUNCTION\_\_或\_\_func\_\_ | 当前函数名的字符串 |
| \_\_LINE\_\_ | 当前行号的整数 |
| \_\_DATE\_\_ | 当前日期的字符串 |
| \_\_TIME\_\_ | 当前时间的字符串 |
