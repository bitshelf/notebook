# Rockchip 平台系统适配
目前 Rockchip 平台系统适配主要是通过 overlay 的方式，通过脚本、so 等进行适配
- 主要包含：
	- 显示服务的适配 (GPU、RGA、drm-cursor)
	- 编解码服务的适配（VPU）
	- camera 服务的适配（ISP）
	- WiFi/BT 服务的适配
	- pulseaudio 服务的适配
	- NPU 服务的适配（NPU）
