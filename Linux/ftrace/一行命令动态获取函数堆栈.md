# 一行命令动态获取函数堆栈
我们很多时候想知道动态执行到Linux kernel中任意一个函数的堆栈，我们可以使用function tracer，例如：
```shell
echo blk_update_request > ./set_ftrace_filter
echo function > ./current_tracer
echo 1 > ./options/stack_trace  
```
也可以不使用`function tracer`, 使用`kprobe_event`来获取。

但是上面的操作都太过于繁琐，很多时候，在enable function tracer的时候也并不想所有的函数都输出堆栈信息。

使用下面一条命令搞定收工，成功吸引你们公司妹子的目光：

```shell
echo 'blk_update_request:stacktrace:3' > ./set_ftrace_filter
```

上面的格式形式`(function:trigger[:count]`)

完整例子如下：  

```shell
# cd /sys/kernel/debug/tracing
echo 'blk_update_request:stacktrace:3' > ./set_ftrace_filter
```
